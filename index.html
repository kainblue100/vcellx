表观遗传先验，到底有没有用

单细胞扰动数据能告诉你「敲掉某个基因之后细胞怎么变」。但如果想预测没做过的组合， 一个自然的想法是引入表观遗传的先验知识 —— 染色质可及性、转录因子结合、染色质接触。 问题是：这些先验真的带来信息，还是只是让模型看到了更多特征？ 这一页讲我怎么把这两个解释分开测量。

00 / 问题

为什么之前的比较说不清

文献里「表观先验是否有帮助」两种结论都有。多数比较把三件不同的事混在一起测， 所以结论互相矛盾，也说不清到底哪一环起了作用。

  • ① 拓扑信息图的连接方式是否携带调控信息。这是我们想证明的。
  • ② 信息量图传播天然让模型看到邻居基因的特征。赢了可能只是输入更多。
  • ③ 过拟合模型可能记住了训练集里的靶基因响应，换一个靶基因就失效。

如果只拿「有图」和「没图」比，① 和 ② 就分不开 —— 有图那一侧输入维度天然更大。 所以我的设计里必须有第三个臂：它看到同样多的信息，但拓扑是随机的。

01 / 数据

02 / 设计

同一骨干，三个臂，只改一个变量

三个臂的编码器、解码器、逐靶基因嵌入、优化器、步数、数据完全相同。 唯一变化的是条件向量里那一项表观通路。

没有 shuffle 这一臂， graph 胜过 direct 是无法解释的 —— 它可能只是输入更大。打乱臂把「看到多少」固定住，只让「谁连谁」变化。

04 / 预训练

先学一个细胞表示，再接表观通路

扰动模型之前先训练一个细胞编码器。做法是掩码表达建模： 每个细胞随机遮住 30% 的基因，用剩下的 70% 编码成单个向量，然后 只从该向量重建被遮住的位置。

「只重建被遮住的位置」是关键。如果对全部位置算重建损失，恒等映射就能把损失压得很低， 编码器什么也学不到。

05 / 损失

为什么比的是分布，不是细胞

单细胞测序是破坏性的。扰动前的状态和扰动后的状态不可能来自同一个细胞， 所以逐细胞配对在原理上不成立。模型因此比较两个细胞集合的分布， 用最大均值差异（MMD，能量距离核）。

MMD² = 2·E‖x−y‖ − E‖x−x′‖ − E‖y−y′‖

三项分别是跨集相似度、预测集内部相似度、观测集内部相似度。两个集合完全重合时三项相等，MMD² = 0。

实现上有个容易写错的地方：内部两项必须排除对角线。否则自距离 0 会把 E‖x−x′‖ 拉低，损失系统性偏小。

06 / 判读

结果怎么读，事先定好

为了避免「看到数字再编故事」，判读规则在实验之前就写死。三种臂之间的关系对应四种结论。

07 / 评测

cell-eval 的三类读出口

用 cell-eval2 0.22.0 的官方 vcc2026 preset。 只比表达量相关会误导：一个把所有基因都往同一方向预测的模型也能拿高分。

  • 表达量扰动后表达变化的 Pearson 相关。最直接，但对均值基线太友好。
  • 差异表达DE 基因的 AUPRC、倍数变化 Spearman、top-k 重合率。更贴近研究者实际关心的问题。
  • 效应量扰动的整体强度排序。不看具体哪些基因，对噪声更稳健。

08 / 限制

最大的方法学弱点，写在显眼处

表观先验与表达数据不是同一个细胞背景

Arc VCC 训练集的 README 没有写明细胞系。磁盘上可用的公共表观数据是 K562（ATAC、CTCF/SP1/USF1 ChIP、Hi-C、WGBS）。

因此这里构建的 GRN 是一个跨背景的人类调控先验， 不是为该表达数据匹配的网络。这会让「图是否有用」的检验更难跑出正结果； 即使 graph 胜出， 也不能据此推断「在这个细胞里表观调控是这样的」。

其它限制。 预训练语料目前只用了 Tabula Sapiens，Orion 与 Tahoe 的观测细胞尚未加入； 图传播是单跳的，没有多跳也没有注意力加权； WGBS 甲基化特征已下载但尚未接入； 集合大小固定 64，未做超参搜索； 服务器为共享环境，实测只有约 4 核可用（请求 16 线程）。

未做的防护也记录在这里：没有用嵌套靶基因折来选超参； 预训练语料与评测数据可能共享细胞类型，这一点尚未审计。
